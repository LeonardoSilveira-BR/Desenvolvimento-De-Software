# Repositório para a disciplina de Desenvolvimento de Software – UFRGS.
O QUE ENTREGAR?

A entrega da Fase 1 do Trab. Prático inclui (Tudo em um arquivo ÚNICO, de preferência PDF ):

a) Lista de requisitos (enumeração de frases em português descrevendo os requisitos funcionais, ou seja, o que se espera que o software faça):
Uma lista de requisitos de software é formada por sentenças que expressam as necessidades do cliente e definem a qualidade do software.
Os requisitos devem ser claros, precisos e objetivos. 

Dicas de como escrever uma sentença de requisito de software:
  Use frases curtas e afirmativas
  Evite frases negativas
  Use a palavra "deve" para indicar o que o sistema deve fazer
  Escreva como uma sentença completa, com sujeito e predicado
  Seja específico sobre o que o sistema deve fazer
  Seja mensurável para que se possa verificar se o sistema está a cumprir as especificações
  Seja alcançável dentro do prazo definido
  Seja relevante para o sistema em questão

Exemplos de requisitos de software:

  O sistema deve cadastrar o cliente rapidamente
  O sistema deve emitir um recibo para o cliente
  O sistema deve atender às normas do padrão IEEE
  O sistema não pode perder dados do cliente
  O sistema deve cadastrar os usuários de maneira amigável
  O sistema deve fornecer para o usuário a possibilidade de agendamento dos procedimentos solicitados pelos clientes

b) Definição (em qualquer sintaxe) das classes , com atributos e métodos definidos até agora

c) Croqui/maquete/rascunho da Interface com Usuário (GUI).
